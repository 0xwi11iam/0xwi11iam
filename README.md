### Why BreachBench?

The same AI that scores 90% on security trivia scores **5%** when it actually has to hack a live target. BreachBench measures what matters—can an AI **execute** an attack, or just **talk about** it?

| Stage | Score | What It Tests |
| :--- | :--- | :--- |
| CONTROL | 100% | Baseline knowledge |
| RECALL | 94% | Factual recall |
| REASONING | 48% | Multi-step analysis |
| LAB | **5%** | **Live exploitation** |

**836 questions · 4 stages · 6 live labs · 29 topics · 11 providers**
